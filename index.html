Firebase ID Token Generator

Connect to your own Firebase project, authenticate a user, and copy an ID token for API testing.

1. Firebase project configuration

Find these values in Firebase Console → Project settings → General → Your apps → Web app.

2. Sign in

Not connected. Enter your Firebase configuration above.

Enable the relevant providers in Firebase Console → Authentication → Sign-in method. Google popup sign-in requires this site's domain to be authorized.

3. Firebase ID token

Email— UID—

Use this value in Postman → Authorization → Type: Bearer Token. ID tokens are short-lived (typically about one hour).

Postman example

Method: GET

URL: https://api-erp.technikh.com/api/v1/sections?limit=20

Authorization: Bearer Token → paste the ID token above.

Security: Firebase web API keys identify your project and are not server secrets. Never put service-account credentials in this page. ID tokens are sensitive: do not share them or commit them to a repository. This page does not send configuration or tokens to any custom backend.
